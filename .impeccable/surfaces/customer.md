# Customer site
Mode: Operate. Audience: a customer following up on a missing item.
Primary task: send a message or start a new conversation without losing earlier context.
Composition: compact brand header; welcoming heading; main chat with order reference, sender-labelled messages and persistent composer; supporting order/parcel aside.
States: returning conversation fixture, new empty conversation, message sent, attachment selection/removal, local demo reset. Mobile prioritizes chat.
Constraint: independent local demo; no upload/API or agent tools exposed.
